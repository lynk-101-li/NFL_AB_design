# NfL 还原敏感高阶复合物的 cathepsin 截断分析

建议先阅读：

1. `NFL_reduction_sensitive_oligomer_cathepsin_truncation.md`
2. `nfl_reduction_sensitive_fragment_candidates.csv`
3. `nfl_cathepsin_annotated_for_snapgene.gp`

SnapGene 使用：

- 打开 SnapGene。
- File -> Open。
- 选择 `nfl_cathepsin_annotated_for_snapgene.gp`。
- 在 protein sequence/map 视图中显示 Features。

当前核心结论：

- 非还原约 25–35 kDa、DTT 后约 6–12 kDa 的变化优先支持由两个 Cys322 二硫键二聚体组成的反平行四聚体；二聚体＋未知伙伴仍不能排除。
- 二聚体间界面包括卷曲螺旋疏水核心、静电作用和几何/构象互补，不能简化为纯疏水作用。
- 单体候选集中在 aa 280-377 附近。
- 优先验证片段：280-375、281-376、282-377。
