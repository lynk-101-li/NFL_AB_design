# NfL 22 kDa 二硫键二聚体 cathepsin 截断分析

建议先阅读：

1. `NFL_22kDa_disulfide_dimer_cathepsin_truncation.md`
2. `nfl_22kda_disulfide_dimer_fragment_candidates.csv`
3. `nfl_cathepsin_annotated_for_snapgene.gp`

SnapGene 使用：

- 打开 SnapGene。
- File -> Open。
- 选择 `nfl_cathepsin_annotated_for_snapgene.gp`。
- 在 protein sequence/map 视图中显示 Features。

当前核心结论：

- 22 kDa 片段最可能是包含 Cys322 的 NfL coil 2B 片段形成的二硫键同源二聚体。
- 单体候选集中在 aa 280-377 附近。
- 优先验证片段：280-375、281-376、282-377。
